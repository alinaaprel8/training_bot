# Дизайн-документ: Telegram-бот для тренировок с парсингом Markdown

**Дата**: 2026-05-21  
**Статус**: Согласовано с пользователем  

---

## 1. Общее описание проекта
Проект представляет собой многопользовательского Telegram-бота, который позволяет пользователям загружать свои еженедельные программы тренировок в формате Markdown (`.md`), просматривать их по дням, интерактивно редактировать веса, RPE и примечания к упражнениям прямо из чата, а также скачивать обновленный Markdown-файл обратно или редактировать его целиком как текст.

---

## 2. Архитектура и Технологический стек
* **Платформа**: Node.js (JavaScript / CommonJS или ESM)
* **Фреймворк для Telegram-бота**: [grammY](https://grammy.dev/) — современный, быстрый и модульный фреймворк.
* **База данных**: SQLite (через библиотеку `better-sqlite3` для синхронной и быстрой работы).
* **Конфигурация**: `dotenv` для хранения `TELEGRAM_BOT_TOKEN`.

---

## 3. Схема Базы Данных (SQLite)

### Таблица `users` (Пользователи)
* `telegram_id` (INTEGER, Primary Key) — уникальный ID пользователя в Telegram.
* `username` (TEXT) — юзернейм в Telegram (опционально).
* `first_name` (TEXT) — имя пользователя.
* `created_at` (DATETIME, Default: CURRENT_TIMESTAMP).

### Таблица `workouts` (Недели тренировок)
* `id` (INTEGER, Primary Key, Auto Increment)
* `user_id` (INTEGER, Foreign Key -> `users.telegram_id`) — владелец записи.
* `week_number` (INTEGER) — номер недели (из YAML: `week: 21`).
* `start_date` (TEXT) — дата начала недели (`start_date: 2026-05-18`).
* `title` (TEXT) — заголовок недели (например, `# 2026-W21 | DELOAD WEEK | ЕДИНЫЙ ЛОГ`).
* `biometrics` (TEXT, JSON) — биометрические показатели пользователя (вес, сон, настроение).
* `days_data` (TEXT, JSON) — структурированное дерево тренировочных дней, упражнений и параметров.
* `raw_markdown` (TEXT) — оригинальный или перегенерированный текст Markdown.
* `created_at` (DATETIME, Default: CURRENT_TIMESTAMP)
* `updated_at` (DATETIME, Default: CURRENT_TIMESTAMP)

## 4. Формат Markdown и Логика Парсинга

### Пример Markdown-файла шаблона:
```markdown
---
week: 21
start_date: 2026-05-18
biometrics:

---

# 2026-W21 | DELOAD WEEK | ЕДИНЫЙ ЛОГ

Состояние на начало недели:
- Вес: 
- Сон: 
- Настроение: 

---

## Пн (18.05) | Upper Power (Deload) | MODERATE CARB
1. Жим штанги лежа — 55.0 кг, 2 x 8, RPE =
   * Примечание: тяжело шло
2. Армейский жим — 30.0 кг, 2 x 8, RPE =
```

### Логика Парсинга:
1. **YAML Frontmatter**: Парсится с помощью регулярных выражений или библиотеки `js-yaml`. Извлекаются `week` и `start_date`.
2. **Биометрия**: Парсится блок «Состояние на начало недели:» для извлечения параметров:
   * Вес
   * Сон
   * Настроение
3. **Дни тренировок (`##`)**: Текст делится по заголовкам второго уровня. Каждый заголовок определяет день, дату и описание дня.
4. **Упражнения**: Внутри каждого дня парсится нумерованный список:
   * Название упражнения: до первого разделителя ` — `.
   * Параметры упражнения: текст между ` — ` и `, RPE =`.
   * Значение RPE: текст после `RPE =` до конца строки.
   * Примечание (комментарий): если на следующей строке идет отступ и символ списка с текстом `* Примечание: <текст>` или `* <текст>`, то этот текст сохраняется как примечание к данному упражнению.

### Логика Регенерации:
При генерации MD-файла обратно данные берутся из JSON (`days_data` и `biometrics`) и форматируются в строгий Markdown-шаблон. Это гарантирует, что даже после интерактивных изменений в Telegram на выходе получится идеально валидный `.md` файл, который можно загрузить в Obsidian или любой другой редактор.

## 5. Пользовательский интерфейс Telegram (User Flow)

1. **Главный экран**:
   * Приветствие и кнопки со списком всех загруженных недель: `📅 Неделя 21 (с 18.05)` и т.д.
   * Кнопка `➕ Загрузить неделю` (или простое перетаскивание `.md` файла).
2. **Экран конкретной недели**:
   * Показывает заголовок и текущую биометрию.
   * Кнопки тренировочных дней (например, `📆 Пн (18.05) | Upper Power`).
   * Сервисные кнопки: `📊 Изменить биометрию`, `📥 Скачать MD`, `📝 Редактировать текстом`, `‹ Назад`.
3. **Экран дня тренировки**:
   * Показывает полный отчет по дню (упражнения, веса, RPE, примечания).
   * Inline-кнопки по каждому упражнению для быстрого перехода к редактированию: `1. Жим штанги лежа (55.0 кг, RPE = 8)`.
4. **Редактирование упражнения**:
   * Выбор параметра для редактирования: `⚖️ Изменить Вес / Параметры`, `⏱️ Указать RPE`, `💬 Добавить примечание`.
   * Изменение параметров происходит через запрос ввода текста в чат или (для RPE) через кнопки выбора от `5` до `10`.

---

## 6. План Тестирования
* **Модульные тесты**: Проверка парсинга корректных и некорректных Markdown-файлов, сверка JSON с ожидаемым результатом.
* **Интеграционные тесты**: Проверка генерации Markdown обратно из JSON структуры без потери данных.
* **Ручное тестирование бота**: Эмуляция диалога в Telegram, проверка работы inline-меню grammY.

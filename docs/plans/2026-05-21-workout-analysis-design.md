# Дизайн-документ: Модуль Анализа Тренировочной Активности и Визуализации

**Дата**: 2026-05-21  
**Статус**: Согласовано с пользователем  

---

## 1. Назначение модуля
Модуль предназначен для сбора статистических показателей по тренировочным дням и неделям, расчета тоннажа по мышечным группам (на основе классификации «Базовые упражнения + Подсобка»), а также построения графиков динамики веса тела, среднего RPE и общего тренировочного объема за все недели.

---

## 2. Алгоритмы сбора метрик и классификации

### Расчет объема:
1. **Тоннаж**: Считается только для силовых упражнений, содержащих числовой вес в кг (например, `55.0 кг, 2 x 8`). Формула: `вес * подходы * повторения`.
2. **Рабочие подходы**: Количество подходов (первое число в `подходы x повторения`).
3. **Среднее RPE**: Среднее арифметическое непустых RPE упражнений.

### Классификатор мышечных групп:
При парсинге упражнения его название сопоставляется с регулярными выражениями:
* **Грудь**: `жим.*лежа`, `жим.*наклон`, `сведения`, `брусья`, `пек-дек`, `разводка` (без слова `стороны`).
* **Ноги**: `приседан`, `сед`, `румынск`, `сгибан.*ног`, `разгибан.*ног`, `голень`, `носки`, `выпад`, `икры`, `становая.*тяга`.
* **Спина**: `тяга.*блока`, `тяга.*горизонт`, `подтягиван`, `гиперэкстенз`, `тяга.*в.*наклон`.
* **Плечи**: `армейск`, `жим.*стоя`, `жим.*сидя`, `разводка.*стороны`, `махи`, `face pulls`, `дельт`, `шраг`.
* **Руки**: `бицепс`, `трицепс`, `разгибан.*блок`, `сгибан.*рук`, `молот`, `французск`.
* **Кор**: `пресс`, `планка`, `подъем ног`, `скручиван`.

---

## 3. Архитектура и Интеграция

### Текстовые отчеты:
* Добавление инлайн-кнопок `📊 Анализ недели` в меню недели и `📊 Анализ дня` в меню дня.
* **Анализ дня**: Бот собирает все упражнения за этот день, делит их по мышечным группам, считает объем по каждой группе, общий объем, подходы и среднее RPE.
* **Анализ недели**: Собирает данные за всю неделю, сопоставляет вес тела и среднее RPE, выдает сводные показатели и кнопку для построения графиков.

### Построение графиков (QuickChart.io):
Бот собирает историю всех загруженных недель для данного пользователя из базы данных, сортирует по дате и формирует Chart.js конфигурацию для QuickChart:
* **Тип графика**: Совмещенный (линейный + столбчатый).
* **Метрики**:
  * Столбцы (ось Y правая): Общий тоннаж за неделю (в тоннах).
  * Линия 1 (ось Y левая): Динамика Веса Тела (кг).
  * Линия 2 (ось Y левая): Среднее RPE.
* Бот запрашивает картинку через HTTP-запрос к `https://quickchart.io/chart` и отправляет полученный PNG-файл пользователю в чат в ответ на запрос.
